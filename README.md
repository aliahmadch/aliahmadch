## About

Ali Ahmad is a GIS and GeoAI developer with a background in Geo-informatics Engineering and experience building full-stack geospatial applications. His work combines GIS, remote sensing, machine learning, spatial databases, and modern web technologies to turn complex geospatial data into practical tools for research, planning, and decision-making.

He is currently pursuing an MSc in Sustainable Design Engineering at the University of Prince Edward Island, with interests in spatial intelligence, AI-assisted environmental monitoring, precision agriculture, and decision-support platforms.

## Selected Work

### Agriculture and Built-Up Land Use Planning
Full-stack geospatial planning platform for Blue Mountains, Ontario, integrating remote sensing, GIS, AI, and GeoAI to classify land use, monitor urban expansion, and support sustainable agricultural planning.

### Coastal Erosion and Vulnerability Assessment
Web GIS portal for Prince Edward Island coastal erosion monitoring using Google Earth Engine, Flask, Python, React, JavaScript, and Leaflet for near real-time visualization and decision support.

### Agricultural Boundary Delineation
Deep learning and GIS workflow for identifying and mapping agricultural field extents using ArcGIS Pro, ArcGIS AI models, GeoAI techniques, and QGIS.

### Carbon Emission Analysis for PEI Farmlands
Full-stack application for processing and visualizing carbon emission datasets, with shapefile and CSV upload, data cleaning, spatial splitting, and downloadable geospatial outputs.

### PEI Land Use and Land Cover Analysis
Remote sensing project quantifying changes in water bodies, vegetation, and built-up areas using LULC classification, confusion matrices, and accuracy assessment.

### GIS Dashboard for Islamabad Schools
Interactive dashboard using JavaScript, Leaflet, Node.js, and PostgreSQL to map schools, manage markers, and store spatial and attribute data.
